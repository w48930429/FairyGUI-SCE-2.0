## 功能摘要

当前战斗 UI 没有“选择服务器（区服）”入口，玩家无法在客户端显式选择 `S1/S2/S3`，也无法看到服务端当前认可的区服状态。   这会导致调试和多区服进度隔离场景不可用：服务端只能用固定 player key，客户端对当前区服无感知。
